## 二、真实数据各阶段输出

序列 00164_FV / 00165_MVL / 00166_MVR / 00167_RV，原始 1280×966。
虚拟相机视口：**150°×120°，pitch=0，roll=0**，640×297，f=85.74 px。

### 2.1 阶段 ①：Y 通道灰度

![Y 通道](viz/sheet_1_y.png)

四路原图取 BT.601 亮度（`Y = 0.299R + 0.587G + 0.114B`），非加权平均。
与 Python 参考逐像素比对 max|Δ| = 0。

### 2.2 阶段 ②：视口投影（6 视口）

![视口投影](viz/sheet_2_view.png)

| 视口 | 相机 | yaw | LUT 有效 | 视差有效 |
|---|---|---|---|---|
| FV_p−45 | FV | −45° | 62.7% | 24007 (12.6%) |
| FV_p+45 | FV | +45° | 62.7% | 13611 (7.2%) |
| RV_p−45 | RV | −135° | 58.0% | 24772 (13.0%) |
| RV_p+45 | RV | +135° | 58.7% | 18547 (9.8%) |
| ML | MVL | +90° | 53.0% | 37680 (19.8%) |
| MR | MVR | −90° | 52.8% | 14444 (7.6%) |

**LUT 有效率 53–63% 是几何必然**：150° 水平张角超出单张鱼眼的能力
（最大半角约 112°），视口边缘采样不到原图像素。红色区域即此。

### 2.3 阶段 ③：前一帧对齐到当前帧方向

![对齐](viz/sheet_3_view_ref.png)

两帧用**同一份 LUT**，故视口方向严格对齐；位移表现为径向缩放。
本帧 ego 位移 273 mm。

### 2.4 阶段 ④：视差图

![视差](viz/sheet_4_disp.png)

`d_max = 46.8 px`（f=85.74、b=273mm、Z_min=0.5m）。
有效视差率 7.2–19.8%——f 从 184.75 降到 85.74 后同一基线的像移减半。

### 2.5 阶段 ⑤：体素 BEV（6 视口 FOV 分色）

![BEV](viz/sheet_5_bev.png)

- 占用栅格 **1339** 个（200mm 体素，90×75×15）
- 六视口分别为红/橙/绿/青/紫/品红，灰白 = 多视口重叠（**54454 px**）
- 细线是各视口 FOV 扇形边界，虚线为中轴

带图例版本：`viz/05_bev_legend.png`

### 2.6 阶段 ⑥：三角化与方差传播

| 指标 | 数值 |
|---|---|
| 候选点 | 61197 |
| 插入成功 | 61197 |
| 超距丢弃（>20m 退化解） | 16267 |
| D3 FoE 锥内剔除 | 0 |
| 表满 / 网格外 | 0 / 0 |

**σ 分布（cm）**

| <10 | <30 | <60 | <100 | ≥100 |
|---|---|---|---|---|
| 22997 | 11586 | 6866 | 5015 | 14733 |

σ 随距离单调增长，符合 `σ_Z = (f·b/d)·√[(σ_d/d)² + σ_odom²]`。
≥100cm 占 24%——这些点集中在近场边缘与弱纹理区。

**D3 剔除为 0** 是正确结果：本帧平移沿车体 +X，六个视口的光轴与之
成 45°–135°，视线与平移方向夹角都远超 8° 锥半角，没有点落在盲区内。
该过滤器在"视口正对行驶方向"时才会触发。

## 三、pipeline 端到端

```
nfocc_run --hanqtech datasets/fisheye --ws-frame 164 --frames 3 --stats
  帧数 3, 平均耗时 34.0 ms/帧, 累计点数 1329 (444/帧)
```

| 项 | 值 |
|---|---|
| 单帧耗时 | 34.0 ms（时间片预算 200 ms，占用 17%） |
| 每帧点数 | 443 |
| 测试 | ctest 13/14，`test_algo_rev` 12 用例 69 断言全过 |

`depth_accuracy` 仍失败，根因是**测量口径**（把产出点投回真实相机像素

实测误差 0.9%，三角化链路在真实数据上产出落在 581–2762 mm 合理区间。

## 四、结论

三份文档的**算法内容已全量落地**（9 个 API、12 个测试用例覆盖），
工程步骤 6 个中 5 个完成。剩余 4 项都是**接线**而非算法缺失，
其中 3 项受当前 ICD 限制（无反向视差、无双基线执行、无绝对位姿）。

真实数据端到端跑通，六个阶段产物齐全，BEV 覆盖四个方向。
