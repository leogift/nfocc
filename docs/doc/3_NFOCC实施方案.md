# NFOCC实施方案

> **定位**：原 NFOCC 的算法替代方案 ｜ **基线来源**：陀螺仪 / Ego Motion（替代 SfM） ｜ **视差引擎**：SGBM（资源受限档）/ StereoNetPlus（精度优先档） ｜ **输入**：四路环视鱼眼无畸变展开


## 1. 需求重定义：什么变了，什么没变

### 1.1 替代的动机与代价

原 NFOCC 用 SfM 从图像序列中同时估计位姿与深度，优势是无需外部里程计，但代价是**位姿漂移直接污染深度**，且纯旋转或极低速时基线退化。改用陀螺仪/Ego Motion 提供基线后，**基线的瞬时值来自独立传感器，不再依赖图像匹配质量**，这是工程上的显著优势。但代价同样明确：**陀螺仪/轮速计的角度噪声与尺度误差会直接进入深度公式**，且当车辆处于纯旋转（绕垂直轴原地转向）或静止时，运动基线为零，系统必须显式检测并暂停视差输出，而非像 SfM 那样“强行”给出深度。

### 1.2 不可替代的部分

原 NFOCC 中与基线来源无关的模块应**完整保留**：车身 ROI 掩码、双向光流遮挡检测、FoE 发散锥过滤、32-bit 体素 Hash、CMA 质心聚合、zMap/zIndex 高程压缩、SERL/DataFrameServer 交付链路。这些是空间离散化与下游接口的工程资产，与视差引擎无关。

### 1.3 新增的系统级需求

| 需求 | 目标值 | 验收方式 |
| :--- | :--- | :--- |
| 运动基线有效性判定延迟 | ≤ 50 ms | 注入纯旋转工况，从“基线失效”到体素输出暂停的时间 |
| 陀螺仪基线尺度误差贡献的深度相对误差 | ≤ 2%（在 2 m 处，横摆角速度 < 10°/s 时） | 转台 + 激光跟踪仪对比 |
| SGBM 档单帧视差计算延迟 | ≤ 15 ms（1080p 展开图，ARM A72 单核 NEON） | 离线 profiling |
| StereoNetPlus 档推理延迟 | ≤ 35 ms（等效 J5 BPU 算力约束下） | 模型量化后板端实测 |
| 视差有效点率（近场 1–5 m） | ≥ 70%（纹理丰富工况）/ ≥ 40%（弱纹理工况） | 标注数据集统计 |

**关键取舍**：原 NFOCC 的 SfM 在静止时可以通过多帧累积“制造”基线，而外部位姿基线下**静止即无基线**。因此系统必须在 APA 低速蠕行工况下接受“输出断续性”——体素点云在车速低于阈值时暂停更新，下游需能容忍该行为。这是架构层面的约束，不是可以通过参数调优消除的。


## 2. 鱼眼无畸变展开：极线对齐是硬前提

### 2.1 展开类型的选择

SGBM 和 StereoNetPlus 都假设输入图像**行对齐**（极线水平）。鱼眼原始图像中极线是曲线，直接匹配不可用。展开类型的选择直接决定这一前提能否成立：

- **经纬展开（equirectangular）** ：极线落在同一水平行上，是全向立体匹配的标准前提，但图像上下两端存在显著拉伸畸变。
- **柱面展开**：保留完整视场，极线畸变较小，但在大俯仰角区域仍可能残余行偏移。
- **分块针孔矫正**：将鱼眼图像划分为多个虚拟针孔平面，每块单独匹配，保证每块内部行对齐，代价是块间边界处的视差不连续。

**可执行决策**：近场地面主导区域使用**柱面展开 + 残余极线偏移的亚像素预补偿**；对极线对齐要求严格的 StereoNetPlus 档，切换到经纬展开或分块针孔矫正。柱面展开后仍存在的行偏移应在匹配前通过离线 LUT 做逐行位移校正，而非依赖匹配算法自身的局部搜索容忍。

### 2.2 展开分辨率的量化约束

展开图的水平像素分辨率决定了给定基线下的视差量化精度。若展开图水平分辨率为 $W_{\text{eq}}$、相机水平视场为 $\Theta$，则每像素对应的方位角为 $\Theta / W_{\text{eq}}$。在给定焦距等效值 $f_{\text{eq}} = W_{\text{eq}} / \Theta$（像素/弧度）下，深度分辨率仍服从 $\Delta Z \approx Z^2 / (f_{\text{eq}} b) \cdot \delta_d$。

**需求**：展开图水平分辨率不应低于原始鱼眼有效像素的水平分辨率；若因算力限制降采样，**降采样后的 $f_{\text{eq}} \cdot b$ 必须重新代入深度分辨率公式，确认 200 mm 体素在目标距离上的不确定度仍可被 CMA 收敛**。若降采样导致 $\Delta Z_{\min} > 200\text{ mm}$（在 3 m 处），则该降采样档位不可用于体素生成，只能用于远距离粗略提示。


## 3. 运动基线：从“图像估计”到“传感器给定”的工程重构

### 3.1 基线的来源与噪声模型

陀螺仪提供角速度 $\boldsymbol{\omega}$，轮速计或 Ego Motion 提供速度 $\mathbf{v}$。帧间平移的估计为 $t \approx \mathbf{v} \Delta t$，基线 $b = \|t\|$。与 SfM 不同，这里的 $t$ 的**方向由传感器给出，尺度由轮速计或 Ego Motion 的尺度确定**，深度误差不再来自“三角化时的基线估计协方差”，而来自**陀螺仪的角度积分噪声**和**轮速计的尺度因子误差**。

深度对基线尺度的敏感度：$\partial Z / \partial b = -Z / b$。即**基线的相对误差以 1:1 传递为深度的相对误差**。若轮速计尺度误差为 2%，则 2 m 处的深度偏差约 4 cm——在 200 mm 体素尺度下可接受。但陀螺仪的角度噪声通过旋转补偿影响极线对齐：当帧间存在横摆角 $\psi$ 时，若角度补偿残余误差为 $\delta\psi$，等效于在展开图上引入行偏移 $\delta v \approx f_{\text{eq}} \cdot \delta\psi$。**在 $f_{\text{eq}} = 200$ px/rad 时，0.1° 的角度残余即对应约 0.35 px 的行偏移**，已接近 SGBM 的亚像素匹配精度极限。

### 3.2 基线有效性的状态机（修订版）

原状态机以 $b_{\min}$ 和 $b_{\max}$ 为核心判据。外部位姿基线下需增加**运动退化检测**：

```text
状态集合：{ IDLE, VALID, ROTATION_ONLY, DEGRADED, OVER_BASELINE }

迁移条件：
  IDLE → VALID:            b ≥ b_min 且 |ω| < ω_thresh 且 轮速有效
  VALID → ROTATION_ONLY:   |ω| ≥ ω_thresh 且 b < b_min（纯旋转，基线为零）
  VALID → OVER_BASELINE:   b > b_max
  VALID → DEGRADED:        陀螺仪与轮速计时序失步 > 5 ms，或轮速尺度自检失败
  ROTATION_ONLY / OVER_BASELINE / DEGRADED → IDLE:  条件解除后重新积累
```

**ROTATION_ONLY 的物理含义**：车辆原地转向时，角速度大但平移接近零，FoE 发散锥无法定义（运动方向不是平移方向），此时**任何视差输出都是不可信的**。系统应显式输出“体素冻结”标志，而非用极小的 $b$ 继续计算导致深度爆炸。这与原 FoE 过滤形成互补：FoE 处理的是“平移存在但视线与平移平行”的区域，ROTATION_ONLY 处理的是“平移本身消失”的全局退化。

### 3.3 基线尺度自检

轮速计尺度受胎压、载荷影响。建议在系统启动后的**直线行驶段**利用已知宽度的地面特征（车道线、停车位标线）做一次尺度校验：将视差反算的某近场刚性目标的宽度与先验宽度比对，若偏差超过 3%，在上报诊断码的同时对基线施加尺度校正因子。这一自检不要求高精度，目的是**防止轮速计脉冲当量因轮胎磨损发生系统性偏移而系统毫无感知**。


## 4. 视差引擎选型：SGBM 与 StereoNetPlus 的分级策略

### 4.1 两种引擎的适用边界

SGBM 在**弱纹理、遮挡、深度不连续**区域会大量产生无效视差或边缘 fattening，这是半全局方法的固有局限。StereoNetPlus 通过多尺度相关性 cost volume 和边缘细化模块，在边缘保留和高频细节恢复上明显优于传统方法，且已针对车规芯片做了 3D 卷积替换与轻量化优化，在 J5 类平台上具备可部署性。但 StereoNetPlus 的**有效工作范围描述为中近距离（5–90 m 量级）** ，而 NFOCC 的近场感知重点在 **0.3–5 m**。这一范围差异需要严肃对待：StereoNetPlus 的预训练与参考指标主要面向车载中距场景，**不能假设其在近场鱼眼展开图上的零样本精度**。

### 4.2 分级策略

| 档位 | 引擎 | 适用条件 | 风险控制 |
| :--- | :--- | :--- | :--- |
| **L0（保底）** | OpenCV `StereoSGBM` | 算力余量紧张、或 StereoNetPlus 未完成近场微调时的默认路径 | 必须启用置信度后处理与遮挡检测；接受较高无效点率 |
| **L1（精度优先）** | StereoNetPlus（近场微调版） | 算力允许且已完成鱼眼展开域上的微调/校准 | 必须做**近场域偏移验证**：在标注的近场数据上确认 EPE 不劣于 SGBM |
| **L2（融合）** | SGBM + StereoNetPlus 残差融合 | 对近场地面与障碍物边缘同时要求高完整性 | 以 SGBM 为稠密底图，StereoNetPlus 仅提供边缘残差修正，不做全图替换 |

**StereoNetPlus 上线的前置条件（硬性）** ：在目标车型的鱼眼展开图上采集不少于 2000 帧近场标注数据（可用激光或标定板生成真值），微调后验证 **0.5–3 m 范围内的深度误差中位数不超过 SGBM 的 110%**。未通过此验证前，StereoNetPlus 只能作为 L2 的边缘辅助，不能作为主视差源。

### 4.3 SGBM 的关键参数约束

`StereoSGBM` 返回的视差以 **1/16 像素为单位**，代码中必须除以 16 后再代入 $Z = f_{\text{eq}} b / d$。`numDisparities` 必须为 16 的整数倍，且其上限直接对应**最近可测距离**：$Z_{\min} = f_{\text{eq}} b / (numDisparities/16)$。以 $f_{\text{eq}} = 200$ px/rad、$b = 200\text{ mm}$、`numDisparities = 128`（即 8 px）为例，$Z_{\min} \approx 5\text{ m}$——**这覆盖不了近场 0.5 m**。近场必须使用更大的 `numDisparities` 或更小的展开分辨率（即更小的 $f_{\text{eq}}$），**参数整定必须从目标 $Z_{\min}$ 反推，而不是沿用中距双目配置**。


## 5. 修订后的系统 Pipeline 与模块契约

```text
[S1] 鱼眼采集 + 陀螺仪/轮速（硬件同步，偏差 ≤ 1 ms）
      ↓
[S2] 无畸变展开 + 极线对齐（LUT 逐像素映射，输出有效性掩码）
      ↓
[S3] 基线状态机（VALID / ROTATION_ONLY / OVER_BASELINE / DEGRADED）
      ↓ 仅 VALID 路径输出 b 与帧间旋转
[S4] 视差引擎（SGBM 或 StereoNetPlus，输入：已对齐展开图对 + 基线范围先验）
      ↓ 输出：视差图 + 置信度图 + 无效掩码
[S5] 三角化 + 不确定度传播（σ_spatial 含像素项与基线尺度项，分层实现）
      ↓
[S6] 体素 Hash + CMA + 遮挡防御（车身掩码、双向光流、FoE、双基线验证）
      ↓
[S7] zMap/zIndex 压缩 → SERL → DataFrameServer
```

### 模块契约（新增/修订项）

| 模块 | 输入 | 输出 | 失效时的行为 |
| :--- | :--- | :--- | :--- |
| **展开与对齐** | 原始鱼眼 + 离线 LUT | 对齐展开图 + 逐像素有效性 + 残余极线偏移场 | 有效性为 0 的像素不参与匹配 |
| **基线状态机** | 陀螺仪 $\omega$、轮速 $v$、时间戳 | $b$、帧间 $R$、状态标志 | `ROTATION_ONLY` / `DEGRADED` 时**阻断 S4**，下游收到体素冻结 |
| **视差引擎** | 对齐展开图对、$[d_{\min}, d_{\max}]$ 先验（由 $b$ 与目标 $Z$ 范围反推） | 视差、置信度、无效掩码 | 置信度低于阈值的像素在 S5 中跳过，而非填充 |
| **不确定度传播** | 视差、$b$、$\sigma_{\text{pixel}}$、$\sigma_b$ | $\sigma_{\text{spatial}}$（mm） | 分层计算：像素项逐点，基线尺度项帧级标量 |

**双基线验证的修订**：原 NFOCC 依赖两组图像帧对做交叉验证。外部位姿基线下，辅助“基线”应定义为**同一帧图像但使用不同时刻的基线尺度**（例如主基线 $b_1$ 与 $b_2 = 2b_1$ 的反算结果），而非两对独立图像。验证残差超过 $\max(2\sigma_{\text{spatial}}, 2\cdot\text{mmPerVoxel})$ 时，该体素标记为“未验证”，**不直接剔除**，因为外部位姿基线的误差来源与 SfM 不同，误剔除会过度稀疏化近场点云。


## 6. 参数整定基线（从目标指标反推）

| 参数 | 推荐初始值 | 反推依据 |
| :--- | :--- | :--- |
| `numDisparities`（SGBM） | 256（16 px） | 目标 $Z_{\min} = 0.5\text{ m}$，$f_{\text{eq}} = 200$，$b = 200\text{ mm}$ |
| `b_min` | 40 mm | 低于此值时视差量化误差主导深度误差 |
| `b_max` | 400 mm | 重叠视场 ≥ 30% 展开图宽度，且视差不超过 `numDisparities` 上限 |
| `ω_thresh`（ROTATION_ONLY） | 12°/s | 该角速度下 50 ms 内横摆角 > 0.6°，已使极线对齐残余超过 1 px |
| 置信度过滤阈值（SGBM） | 无效掩码 + 右左一致性检查 | 利用 `StereoSGBM` 的 `disp12MaxDiff` 与唯一性检查联合门限 |
| $\sigma_b$（基线尺度不确定度） | 0.02·$b$ | 轮速计 2% 尺度误差的保守赋值 |


## 7. 分阶段实施路径

**阶段 A（2–3 周）：SGBM 基线与展开链路的端到端打通。** 完成鱼眼→柱面/经纬展开 LUT、极线残余偏移校正、SGBM 在展开图上的视差输出与三角化，接回原 NFOCC 的体素化与 Hash 模块。验收标准：在静止标定场景（标定板/静态障碍物）上，1–3 m 范围内的体素位置与激光真值的偏差中位数 < 150 mm。

**阶段 B（2 周）：外部位姿基线状态机与退化处理。** 接入陀螺仪与轮速，实现 `ROTATION_ONLY`/`OVER_BASELINE`/`DEGRADED` 判定与体素冻结语义。验收标准：纯旋转工况下系统不输出体素（而非输出错误体素），且恢复直行后在一个基线窗口内重新输出。

**阶段 C（3–4 周，并行）：StereoNetPlus 近场微调与域偏移验证。** 若选用 L1 档，在目标车型鱼眼展开图上采集近场数据并微调；**必须包含与 SGBM 的逐区域对比**。若微调后 0.5–3 m 的 EPE 劣于 SGBM，则 StereoNetPlus 降级为 L2 边缘辅助，不阻塞阶段 A/B 的交付。

**阶段 D（1–2 周）：下游接口回归与失效模式注入。** 将新的体素流经 SERL/DataFrameServer 推送至规划模块，注入弱纹理墙面、纯旋转、轮速计尺度偏移、陀螺仪零偏等失效场景，验证下游不会将冻结/未验证体素误用为可行驶空间依据。


**结论性判断**：该替代方案在工程上是可行的，但**可行性的关键不在于“换一个更先进的视差网络”**，而在于两件事——**经纬/柱面展开后的极线对齐精度必须被量化控制**，以及**外部位姿基线在纯旋转和静止时必须被显式判定为“不可用”而非被 SfM 的“伪鲁棒性”掩盖**。StereoNetPlus 是可选升级项而非前提条件；SGBM 配合正确的展开几何和参数整定，足以支撑第一阶段的可交付系统。
