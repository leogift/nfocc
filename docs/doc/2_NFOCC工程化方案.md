## 2. 运动双目（MOS）几何原理与多视口射线投影模型

### 2.1 运动基线解算与帧配对状态机

（原报告公式保留）

🔧 **工程落地要点：基线状态机的工程化设计**

原报告给出了 $b_{\min} \approx 50\text{ mm}$ 和 $b_{\max}$ 的概念，但未给出**状态机的完整迁移条件**。可指导代码实现的状态机如下：

```cpp
// 状态定义
enum BaselineState {
    IDLE,               // 车速过低，基线不积累
    ACCUMULATING,       // 正在积累运动位移
    READY,              // 基线进入可用窗口
    DEGRADED,           // 角速度超限，暂停输出
    OVER_BASELINE       // 基线超过 b_max，强制重置
};
```

**迁移判据（建议整定基线）** ：

| 条件 | 阈值（初始值） | 动作 | 依据 |
| :--- | :--- | :--- | :--- |
| $\|v\| < 0.05\text{ m/s}$ | 低速死区 | `IDLE → ACCUMULATING` 阻塞 | 轮速计噪声淹没位移信号 |
| $b < b_{\min}$ | $50\text{ mm}$ | 保持 `ACCUMULATING` | 低于此值视差量化误差主导 |
| $b_{\min} \le b \le b_{\max}$ | $b_{\max} = 500\text{ mm}$（建议） | `READY` | 需与 SDE 视差范围联合标定 |
| $b > b_{\max}$ | 同上 | `OVER_BASELINE`，强制重置 | 重叠视场 < 图像宽度的 30% 时匹配失效率陡增 |
| $|\omega| > \omega_{\text{thresh}}$ | $15^\circ/\text{s}$（建议） | `DEGRADED`，仅保留辅助基线 | 旋转导致 FoE 假设失效 |

**双基线选择的工程修正**：原报告“主基线 + 长/短辅助基线”的描述需明确——辅助基线的作用是**交叉验证**而非独立输出。因此辅助基线应满足**与主基线视差分布显著不同**（基线长度比 ≥ 2:1），否则重投影验证退化为近似恒等映射，失去剔除能力。

### 2.2 超广角鱼眼的多视口展开与逆向光线采样

（原报告公式与代码片段保留）

🔧 **补充：柱面展开的极锥“空洞”问题**

原报告未指出柱面视口的**固有视场损失**。当鱼眼相机垂直视场角超过柱面展开所能覆盖的高度角时，柱面顶部/底部会出现数据空白区。球面展开与柱面展开的极锥覆盖差异可达 **15° 量级**（同一图像行，球面 elevation 62.7° vs. 柱面 47.6°）。工程对策：

- **近场地面感知优先使用柱面**（水平极线搜索效率高）；
- **车身侧上方区域（如路沿、低矮障碍物顶部）回退到圆锥面或球面视口**，避免因极锥截断导致的高程信息缺失；
- LUT 中显式存储每个视口栅格点的**有效性标志位**，无效栅格在立体匹配阶段直接置零置信度，而非参与搜索。

🔧 **LUT 的定点精度要求**：`computeLutCoords()` 的坐标插值若使用 8-bit 定点，在鱼眼图像边缘（畸变梯度最大处）可能引入 > 0.5 px 的重采样误差，直接恶化视差精度。建议 **LUT 坐标存储为 Q12.4 格式（16-bit）** ，并配合双线性插值读取鱼眼像素。


## 3. 3D 稠密三角化反投影与空间误差传播模型

### 3.1 柱面视口三角化几何数学推导

（原报告公式保留）

🔧 **补充：深度分辨率的硬下限**

运动双目在近场的深度分辨率并非任意可提升。令视差量化单位为 $\delta_d$（SDE 输出为整像素或 1/2 像素），则深度分辨率近似为：

$$\Delta Z_{\min} \approx \frac{Z^2}{f_{\text{px}} \cdot b} \cdot \delta_d$$

代入典型近场参数（$Z = 3\text{ m}$，$f_{\text{px}} = 300$，$b = 200\text{ mm}$，$\delta_d = 1\text{ px}$）：$\Delta Z_{\min} \approx 150\text{ mm}$。这意味着 **200 mm 体素在 3 m 处的单次观测深度不确定度已接近体素尺度**——因此 CMA 多帧融合不是“锦上添花”，而是**达到标称精度的必要条件**。

### 3.2 物理空间不确定度模型（Spatial Uncertainty）

（原报告公式保留）

🔧 **工程修正：不确定度传播的实现层级**

原报告给出的 $\sigma_{\text{spatial}}$ 公式包含 $\sigma_{\text{pixel}}$ 与 $\sigma_{\text{odom}}$ 两项，但在 DSP 上逐点计算完整传播的算力代价过高。建议**分层实现**：

- **逐点在线量**：仅计算 $\sigma_{\text{pixel}} \cdot |\text{ratio}/\text{disp}|$ 项（与视差直接相关），$\sigma_{\text{odom}}$ 项由帧级标量近似（同一帧内视为常数）；
- **帧级预计算**：$\sigma_{\text{odom}} / \text{disp}$ 的因子可离线制表，在线查表 + 乘法；
- **不确定度下限钳位**：$\sigma_{\text{spatial}}$ 不应小于体素半边长（100 mm），否则下游无法区分“高置信点”与“量化噪声”。

**与文献方差传播的一致性**：深度误差方差 $\sigma_r^2 \propto r^4 \sigma_d^2 / (f^2 b^2)$，即不确定度**随距离四次方增长**。这解释了为何 FoE 附近（$r \to \infty$ 方向）的三角化点不可用——方差在该区域发散，任何阈值都失去意义。

### 4.2 空间坐标离散化与 32-bit 紧凑 Hash ID

（原报告代码保留）

🔧 **关键工程修正：Hash 冲突**

原报告将 `(X<<16)|(Y<<8)|Z` 称为“Hash”，但该式在 $X, Y, Z$ 的取值范围下实际上是**无冲突的位拼接**（$\le 255 \times 255 \times 31$ 的索引空间恰好可被 24 bit 覆盖，剩余 8 bit 可用于 `sourceNumRaw` 计数）。工程上需注意：

- **位拼接本身无冲突**，但 `Tile Scratch` 空间哈希表在**查表定位**时若使用开放寻址，仍可能因表负载因子过高产生探测溢出。建议**负载因子 ≤ 0.7**，探测深度上限设为 4（超过则丢弃该点，避免链式退化）。
- 若未来扩展到更大网格（$X$ 或 $Y$ > 255），位拼接方案失效，需切换为真正的空间哈希（如 Morton 码或乘法哈希），**当前代码必须为此预留接口抽象**。

### 4.3 累积移动平均（Cumulative Moving Average, CMA）

（原报告内容保留）

🔧 **工程修正：CMA 不是 TSDF，不能替换**

原报告在术语上易引起混淆。Voxblox 等系统中的体素融合使用 **TSDF（截断符号距离函数）+ 加权平均**，而 NFOCC 的 CMA 直接对**三角化点坐标**做移动平均，本质是**点云质心估计**而非隐式表面重建。两者不可互换：

- CMA 的优点是**计算极轻**（每个体素仅存质心 + 计数），适合 DSP 实时；
- CMA 的代价是**无法表示“空”与“未知”的区别**——未观测体素和射线穿过但无反射的体素在数据结构上无差异，下游需依赖 `sourceNumRaw` 计数区分；
- 若后续需要可行驶空间中的**自由空间推理**，需在 CMA 之上增加 ray casting 穿透计数，而非改造 CMA 本身。

**CMA 更新式（确认实现一致性）** ：

$$\bar{\mathbf{p}}_{n+1} = \bar{\mathbf{p}}_n + \frac{\mathbf{p}_{\text{new}} - \bar{\mathbf{p}}_n}{n+1}, \quad n \leftarrow n+1$$

其中 $n$ 为有效观测计数（**建议以置信度加权计数 $n \leftarrow n + w_{\text{conf}}$ 替代整数计数**，使低置信观测对质心的拉动更弱）。


## 5. 全流程射线遮挡计算与伪影抑制算法

### 5.1 防御 1：自车物理多边形掩码

（原报告内容保留）

🔧 **工程落地要点**：车身掩码多边形应**膨胀 1–2 像素**再用于 LUT 有效性判定。车身边缘（如后视镜与背景交界处）的混合像素在鱼眼强畸变下极易被误匹配为近处伪点，膨胀可吸收该误差带。

### 5.2 防御 2：双向光流一致性遮挡检测

（原报告公式保留）

🔧 **参数整定依据**：`nOcclusion = 14` 是**置信度压低权重**而非硬阈值。建议将其解释为：当双向一致性残差超过阈值时，该像素的置信度乘以 $1/(1 + n_{\text{Occlusion}} \cdot \text{residual}/\text{threshold})$，使遮挡区像素**软性退出** CMA，而非直接截断。硬截断在纹理丰富区域会造成体素空洞。

### 5.3 防御 3：运动极点发散锥过滤

（原报告代码保留）

🔧 **工程落地要点**：FoE 锥的 apex 不是单点，而是一个**不确定区域**（由轮速计横摆角速度噪声决定）。建议以 FoE 估计值 ± $2\sigma_{\text{FoE}}$ 为 apex 范围，将 `MOS_ptInFoe()` 的判定从“点 vs. 锥”扩展为“点 vs. **锥的包络**”，避免 FoE 估计抖动导致过滤边界闪烁。

### 5.4 终极防御：双基线体素重投影交叉验证

（原报告内容保留）

🔧 **工程修正：验证通过后的不确定度更新**

原报告“验证通过则 `uncertainty_cm >>= 1`”在物理上需谨慎。双基线验证证明该体素在两组独立视差观测下一致，这确实降低了**偶然误匹配**的概率，但**不降低深度分辨率的物理下限**（第 3.1 节）。建议将 `>>= 1` 改为**按验证残差做贝叶斯加权**：

$$\sigma_{\text{verified}}^2 = \frac{\sigma_1^2 \cdot \sigma_2^2}{\sigma_1^2 + \sigma_2^2}$$

即两次观测的信息融合方差。当 $\sigma_1 \approx \sigma_2$ 时，$\sigma_{\text{verified}} \approx \sigma_1/\sqrt{2}$，比简单减半更保守且统计上更合理。

**验证阈值的整定**：`verifyUncertaintyThresh` 不应设为固定常数，建议与 $\sigma_{\text{spatial}}$ 联动——阈值 = $\max(2\sigma_{\text{spatial}}, 2 \cdot \text{mmPerVoxel})$。前者防止过度剔除高不确定度的有效点，后者保证至少一个体素尺度的容差。


## 6. 多相机汇聚、高程图压缩与下游系统交付

### 6.1 2D 高程图位图与 Z-Index 垂直连续柱状压缩

（原报告内容保留）

🔧 **工程落地要点：`zMap` 位图的宽度语义**

`zMap[HeightMapIdx]` 为 32-bit，但 `Height_vx` 可达 31（第 4.1 节），意味着 **31 个垂直体素恰好占 31 bit，剩余 1 bit 必须显式保留为 0 或用作“柱体非空标志”**。代码中若直接 `zMap |= (1u << k)` 且 $k$ 可达到 31，第 32 bit 的符号位在无符号运算中虽不溢出，但下游按 `int32_t` 解读时可能变为负数。建议**统一使用 `uint32_t` 进行位操作**，并在 SERL 序列化前显式检查 bit 31 未被置位。

### 6.2 下游核心接口结构体与通信流

（原报告结构体保留）

🔧 **补充：`spatial_uncertainty_cm` 的量纲陷阱**

字段为 `u8`，单位 cm，有效范围 0–255 cm。但近场远距离（> 5 m）的 $\sigma_{\text{spatial}}$ 可能超过 255 cm，此时发生**饱和截断**。下游若将 255 解读为“不确定度恰好 255 cm”而非“≥ 255 cm”，可能做出过度乐观的碰撞判定。建议在协议层**将 255 定义为哨兵值“不确定度超限”**，下游应将该体素视为不可用于精确测距、仅可用于存在性提示。

## 8. 总结与工程启发（修订）

（原报告四点总结保留，补充以下**工程可执行结论**）

5. **硬件约束是算法设计的硬边界，不是事后优化项**。TDA4 SDE 的**最大视差搜索范围 191 像素**直接限定了在给定 $f_{\text{px}}$ 和 $b_{\max}$ 下的**最近可测距离下限**——当 $b = 500\text{ mm}$ 时，191 px 视差对应约 $0.78f_{\text{px}}$ mm 的最近距离，需在基线状态机中将此作为 `OVER_BASELINE` 的物理依据。**算法参数必须与 SDE 配置联合标定，不可独立整定**。

6. **不确定度传播的工程实现应分层**：逐点在线计算仅保留视差相关项，里程计项帧级近似，避免 DSP 上逐点超越函数运算。

7. **CMA 与 TSDF 的边界需在架构文档中显式声明**：当前系统输出的是**质心点云**而非隐式表面，下游的自由空间推理不能直接复用 TSDF 语义。若后续引入可行驶空间穿透推理，应在 CMA 之上叠加独立模块，而非修改 CMA 本体。

8. **在线外参纠正（MTC）与 NFOCC 的耦合点**在双基线验证残差的**时序趋势**：若验证残差均值在连续 N 帧（建议 N = 50）内单调上升，且与温度/振动信号相关，则触发外参微调，而非继续收紧验证阈值。将残差**趋势**而非**瞬时值**作为纠正触发信号，可避免动态场景导致的误触发。
