# SPEC-CAMERA — 4 路鱼眼相机的数据格式与内参约束

坐标系与 KB 模型见 `SPEC-COORD`，参数值见 `PARAM.md`。本文只规定**相机数据的格式与来源约束**。

---

## 1. 图像格式（用户已定，不可协商）

| 项 | 值 | 约束 |
|---|---|---|
| 通道数 | **单 Y 通道** | 8 bit；无颜色、无 UV 平面 |
| 尺寸 | **1920 × 1536**（W × H） | 四路必须完全一致 |
| 字节序 | 每像素 1 字节 | — |
| 行对齐 | `stride` 可以 > `width` | 引擎按 `stride` 寻址（`SPEC-ICD` E-1） |
| 时间戳 | 微秒，同一帧四路**≤ B_DT_MAX (5 ms)** 偏差 | 跨相机基线要求（见 §4） |

推导量：

| 量 | 值 |
|---|---|
| 单帧大小 | 2.95 MB |
| 4 路单帧 | 11.8 MB |
| 4 路 @20 Hz 带宽 | 236 MB/s |
| 4 路 @30 Hz 带宽 | 354 MB/s |

> **236–354 MB/s 的原始 Y 数据带宽**是必须显式确认的一项（见 `APPENDIX-OPEN` O-7）：
> 若平台内存带宽不足，需在采集侧降采样或按需拷贝，这会影响 `E_DOWNSCALE` 的选择。

---

## 2. KB 内参的约束

```c
NFCameraModel { f, cx, cy, k1, k2, k3, k4, r_valid }
```

| 约束 | 检查 | 违反后果 |
|---|---|---|
| `f > 0` | `f <= 0` → `NF_E_CAM_NOT_CALIBRATED` | 全链路失效 |
| `θ_d(θ)` 在 `[0,θ_max]` 单调 | `θ_d′ > 0` 全程 | 反解不收敛（`NF_E_CAM_DISTORT_INV`） |
| `r_valid ≤ min(W,H)/2` 或更大（按实际） | 见 `SPEC-COORD` 3.4 | 无效应被误判有效 |
| `cx, cy` 落在图像内 | `0 < cx < W` | 主点错 → 全部射线偏 |

### 2.1 `f` 与视场角只能信一个

见 `SPEC-COORD` §3.5 的表。**必须由标定给出 `f`，不要用标称 FOV 反推**。
若只有 FOV，则在 `scene.json` 里标注 `"f_source": "estimated"`，
下游使用 `INF_F` 做精度外推时必须考虑不确定性。

---

## 3. 四路相机的标识

```c
enum { CAM_FV = 0, CAM_RV = 1, CAM_ML = 2, CAM_MR = 3 };
```

- `source_camera` 位图（`SPEC-ICD` §6.2）：`bit0=FV, bit1=RV, bit2=ML, bit3=MR`。
- **禁止**用序号以外的顺序（例如按图像到达顺序）索引相机。

---

## 4. 跨相机的时间约束

4 路相机在**同一帧**内的时间偏差必须 ≤ `B_DT_MAX`。
这直接决定"多相机体素汇聚时同一表面能否落在同一体素"：
20 Hz 下 5 ms 偏差、车速 1 m/s → 5 mm 位移，相对 200 mm 体素为 2.5%，可接受；
若偏差到 50 ms → 50 mm，占 25%，会导致两路结果系统性错位。

**验收**：`V-CAM-1` 检查四路时间戳的极差 ≤ `B_DT_MAX`，超出则该帧整体丢弃并返回
`NF_E_BASELINE_DEGRADED`（不得只用其中三路继续）。

---

## 5. 有效区（R_valid）与视场的关系

见 `SPEC-COORD` 3.4/3.5。补充一条工程约束：

**有效区形状决定了视口能否是矩形。**
若 `r_valid` 使图像上下先于左右失效（1920×1536 下必然如此：短边 768 < 长边 960），
则有效区是**上下被削的椭圆**。视口若按矩形生成，上下两角必然落在无效区，
其 LUT 有效性必须标 0，导致视口上下行的有效宽度变小——这正是
`SPEC-EPIPOLAR` §3.3 要求"每行有效起点可以不同"的另一个原因。

---

## 6. 验收

| 编号 | 级别 | 判据 |
|---|---|---|
| V-CAM-1 | L0 | 四路时间戳极差 ≤ 5 ms，否则整帧丢弃 |
| V-CAM-2 | L0 | `f ≤ 0` 或缺内参时返回 `NF_E_CAM_NOT_CALIBRATED` |
| V-CAM-3 | L0 | `θ_d` 单调检查覆盖 `[0, θ_max]` 1000 采样点 |
| V-CAM-4 | L0 | 图像尺寸非 1920×1536 返回 `NF_E_PARAM_RANGE` |
| V-CAM-5 | L0 | `valid_x0[y]` 与 `valid` 掩码一致（同一次展开产物） |
