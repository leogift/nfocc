# SPEC-COORD — 坐标系与变换约定（唯一权威）

本文档是 NFOCC 中**所有**点、向量、旋转、投影约定的唯一定义处。任何模块实现或文档若与本文件冲突，
以本文件为准；若确需修改，先改本文并登记 `APPENDIX-CHANGELOG`。

---

## 1. 坐标系的定义

### 1.1 车辆坐标系 `V`（ISO 8855）

| 轴 | 朝向 | 说明 |
|---|---|---|
| `X_V` | 车头前向 | 纵向 |
| `Y_V` | 车辆左侧 | 横向 |
| `Z_V` | 竖直向上 | 高程 |

右手系。原点 `O_V`：**后轴中心地面投影点**（ISO 8855 定义）。
单位 mm；角度 rad。

> 实现约束：外部拿到的位姿通常是后轴中心，而本系统输出的体素网格原点在 `Xmax,Ymax,Zmin` 角
> （见 `PARAM.md` 的 `P.GRID_*`）。两者的平移在 `SPEC-ICD.md::GridTransform` 里显式给出，
> **不允许在别处再做一次平移**。

### 1.2 相机坐标系 `C`（OpenCV）

| 轴 | 朝向 | 说明 |
|---|---|---|
| `x_C` | 图像右 | 与像素 `u` 同向 |
| `y_C` | 图像下 | 与像素 `v` 同向 |
| `z_C` | 光轴前向 | 深度方向 |

右手系（`x × y = z`）。单位 mm。

### 1.3 图像坐标系 `I`

像素坐标 `(u, v)`，`u ∈ [0, W)`，`v ∈ [0, H)`，`W=1920, H=1536`。
**像素中心约定**：整数索引 `(u,v)` 对应物理位置 `(u+0.5, v+0.5)`。
所有插值（双线性、LUT 采样）一律按此约定，避免半像素系统偏差。

主点 `(cx, cy)` 单位 px，允许为小数。

### 1.4 视口坐标系 `P`（视口 = 展开图）

视口也是一个针孔相机系，命名 `P`，轴定义与 `C` 相同（x 右 / y 下 / z 前）。
展开图的每一点 `(u_P, v_P)` 反投影后得到一条视口射线，再经旋转落到 `C` 得到鱼眼像素。
视口参数在 `PARAM.md` 的 `P.VIEW_*` 登记。

## 2. 旋转与外参的唯一约定

设相机 `c` 的位姿为 `(R_cv, t_cv)`。

```
R_cv ∈ SO(3)        # 3x3
t_cv ∈ R³           # mm
```

**定义**：`R_cv` 的作用是把 `C` 系的向量转到 `V` 系：

```
v_V = R_cv · v_C                            (2.1)
```

由此得到唯一的投影公式（**全系统只有这一种写法**）：

```
p_C = R_cvᵀ · (P_V − t_cv)                  (2.2)
u = f · p_C.x / p_C.z  + cx                 (2.3)
v = f · p_C.y / p_C.z  + cy
```

其中 `t_cv` 是相机光心在 `V` 系下的坐标。**`P_V` 为同名点的车辆坐标。**

### 2.1 等价的行向量写法（仅为代码实现便利，不得作为新约定）

令

```
M = R_cvᵀ                                    (2.4)
```

则 `p_C = M · (P_V − t_cv)`，`M` 的三行分别就是 `x_C / y_C / z_C` 轴在 `V` 系下的单位向量。

代码里若使用行向量批处理 `P_C = (P_V − t) @ M.T`，必须保证 `M = R_cvᵀ`。
**把 `M` 当成 `R_cv` 用是本项目历史上出现最多的错误来源**（两版探针都栽在这里）。

### 2.2 禁止事项

- 禁止使用 `p_C = R_cv · (P_V − t_cv)`（漏转置）。
- 禁止使用 `v_V = R_cvᵀ · v_C`。
- 禁止在某个模块内部自定义"矩阵的行是轴"或"列是轴"的另一套约定。
- 禁止把 `t_cv` 当作"从相机到车辆"的平移方向自行取反。

### 2.3 自检（实现必须内建，失败即抛错）

对每个相机外参，构造校验：

```
C1  det(R_cv) − 1 < 1e-9  且  R_cv R_cvᵀ − I < 1e-9
C2  把 V 系原点沿 z_C 轴前方 1 m 的点投影，u 必须等于 cx、v 必须等于 cy（误差 < 1e-6 px）
C3  把 V 系原点沿 x_C 轴前方 1 m 的点投影，u 必须 > cx
C4  把 V 系原点沿 y_C 轴前方 1 m 的点投影，v 必须 > cy
```

C3/C4 校验的是"右手系 + y 朝下"没有被翻转——**鱼眼相机上下装反时 C1/C2 仍能通过**。

## 3. 鱼眼内参模型（KB / Kannala-Brandt）

### 3.1 正投影 `C → I`

输入 `p_C = (x, y, z)`，`z > 0`：

```
θ  = atan2( ‖(x,y)‖ , z )                                  (3.1)
θ_d = θ (1 + k1 θ² + k2 θ⁴ + k3 θ⁶ + k4 θ⁸)                (3.2)
r  = f · θ_d                                               (3.3)
u  = cx + r · (x / ‖(x,y)‖)                                (3.4)
v  = cy + r · (y / ‖(x,y)‖)                                (3.5)
```

`‖(x,y)‖ = 0` 时 `(u,v) = (cx,cy)`。

参数：`f, cx, cy, k1..k4`（每个相机一组，登记在 `PARAM.md` 的 `INF_<CAM>_*`）。

### 3.2 反投影 `I → C`（视口 LUT 必须用它）

给定 `(u,v)`：

```
mx = (u − cx) / f ;  my = (v − cy) / f                     (3.6)
r_d = sqrt(mx² + my²)                                       (3.7)
θ   = θ_d⁻¹(r_d)        # 见 3.3 的数值反解                   (3.8)
ρ   = sin θ ;  σ = cos θ
ray_C = ( mx/‖(mx,my)‖ · ρ , my/‖(mx,my)‖ · ρ , σ )         # 单位向量 (3.9)
```

### 3.3 θ_d 的反解

`θ_d(θ)` 在 `θ∈[0, θ_max]` 上单调增（**前提**：`k1..k4` 满足单调性，见 3.4）。
用 Newton 迭代，初值取 `θ⁽⁰⁾ = r_d`（`θ_d ≈ θ` 的一阶近似）：

```
θ⁽ⁱ⁺¹⁾ = θ⁽ⁱ⁾ − (θ_d(θ⁽ⁱ⁾) − r_d) / θ_d′(θ⁽ⁱ⁾)            (3.10)
```

终止条件：`|θ_d(θ) − r_d| < 1e-9` rad，最多 10 次。**不收敛时返回 `NF_E_CAM_DISTORT_INV`**（`SPEC-ICD`）。

`θ_d′(θ) = 1 + 3k1θ² + 5k2θ⁴ + 7k3θ⁶ + 9k4θ⁸` （注意：**×1, ×3, ×5, ×7, ×9**，易写成 ×1,2,3,4）。

### 3.4 有效像素区（必须显式定义）

鱼眼图像是圆形成像，1920×1536 的四角通常**没有有效数据**。定义：

| 项 | 定义 |
|---|---|
| `R_img_max` | 以 `(cx,cy)` 为中心、能覆盖全图的最大半径 = `√(960²+768²) = 1229.4 px` |
| `R_valid(cam)` | **有效半径**，标定给出（`PARAM.md` 的 `INF_<CAM>_R_VALID`）；`r_d·f > R_valid` 判为无效像素 |

**关键：有效半径受图像短边限制**。以中心为准，上下方向最多 `H/2 = 768 px`，左右方向最多 `W/2 = 960 px`。
所以有效区在多数鱼眼下是**椭圆/被裁的圆**，不是一个完整圆。

### 3.5 视场角与 f 的耦合（必须由标定确定，不要用"190°"反推）

视场角与 `f`、`R_valid` 三者只有两个独立。常见误区是用"标称 FOV=190°" 反推 `f`，
但那个 FOV 通常是**对角线**且包含已被裁掉的四角。等距近似（`k=0`）下的实算：

| f (px) | R=768 处半视场 | R=960 处半视场 | 对应全视场（水平方向，R=960） |
|---|---|---|---|
| 600 | 73.3° | 91.7° | 183° |
| 700 | 62.9° | 78.6° | 157° |
| 800 | 55.0° | 68.8° | 137° |
| 900 | 48.9° | 61.1° | 122° |

**结论：在 f 未标定前，"有效水平 FOV" 无法确定，而它直接决定视口张角与体素覆盖。**
默认值 `f = 700 px`（`PARAM.md::INF_F`），对应水平全视场约 157°、
垂直方向被裁到 `±62.9°`（≈126°）。
**这是 `APPENDIX-OPEN.md` O-1 的来源，属于必须尽早标定的一项。**

> 与体素网格的关系（定案值 f=550、`POS_CAM_Z`=700、`POS_PITCH`=0°，实算）：
> 垂直半视场 = 80.0°（上下边缘 θ=768/550），**若用整个视场**会从 123 mm 一路看到地平线，
> 其中地平线附近视差为零。因此**实际只用视口环带** `V_RING_EL_MIN/MAX`（见 `PARAM.md`）：
> 取 10°–60° 时地面覆盖 **404–3970 mm**。
>
> 结论：**近场地面覆盖由"高度 + 环带角"决定，不由 `Z_max`/`X_max` 决定**；
> 体素网格的范围是"能放下的空间"，视口环带是"能看到的空间"，两者必须分别核算。

## 4. 位姿与基线

### 4.1 帧间相对位姿

设时刻 `t₁` 与 `t₂` 相机在 V 系的位姿为 `(R₁, t₁)`、`(R₂, t₂)`（`R` 为 `R_cv`）。

```
R_rel = R₁ᵀ · R₂             # C₁ → C₂ 的旋转                (4.1)
t_rel = R₁ᵀ · (t₂ − t₁)      # 平移在 C₁ 系下的表示           (4.2)
基线  b = ‖t₂ − t₁‖  (mm)                                   (4.3)
```

**运动双目的极线与视差全部在 `C₁` 系内表达**，`t_rel` 是唯一的平移来源。

### 4.2 视差定义与符号

对同一点 `P`，在 `C₁`、`C₂` 下的投影为 `(u₁,v₁)`、`(u₂,v₂)`（已按 `t` 方向重排到同一图像行）。

```
视差  d = u₁ − u₂   (px)                                    (4.4)
```

符号约定：**相机向右移动时 `u` 减小，故 `d > 0`**。
所有引擎的输出必须是这个符号。若某引擎给出相反符号，适配层取反并在 `SPEC-ENGINE.md` 登记。

## 5. 离散化约定

### 5.1 体素网格

体素边长 `vox_mm`（`PARAM.md::G_VOX`）。网格索引 `(ix, iy, iz)` 与车辆坐标的映射：

```
ix = floor((X_max − X_V) / vox_mm)      # X 方向反向: 靠近 X_max 的体素 ix=0
iy = floor((Y_max − Y_V) / vox_mm)      # Y 方向同样反向
iz = floor((Z_V − Z_min) / vox_mm)      # Z 方向正向
```

**反向的原因**：与原始 NFOCC 的 Hash 拼接保持位序一致（高位是纵向）。
反向如果不一致，多帧融合时同一物理点会落到不同体素，且不易察觉。

索引范围：`ix ∈ [0, NX)`，`iy ∈ [0, NY)`，`iz ∈ [0, NZ)`，`NX/NY/NZ` 由 `PARAM.md` 给出。

### 5.2 体素中心

索引 `(ix,iy,iz)` 代表的物理点取其**中心**：

```
X_c = X_max − (ix + 0.5)·vox_mm
Y_c = Y_max − (iy + 0.5)·vox_mm
Z_c = Z_min + (iz + 0.5)·vox_mm
```

所有"体素坐标"报给下游的一律是中心点，不是左下角。

### 5.3 哈希与索引打包

32 位打包（位宽在 `PARAM.md::P_HASH_BITS` 登记，随网格规模变化）：

```
hash = (ix << 16) | (iy << 8) | iz      # 默认位宽, 要求 ix,iy ≤ 255, iz ≤ 255
```

**冲突判定**：本打包在 `NX,NY,NZ ≤ 256` 时无冲突（是位拼接不是散列）。
若网格扩展到超过 256，必须改接
`SPEC-CONFLICT` 标记的替代方案，**不允许静默截断**。

## 6. 角度、弧度与查表的精度约定

| 项 | 约定 |
|---|---|
| 角度单位 | 内部一律 rad；对外接口若用 deg，符号带 `_deg` 后缀 |
| LUT 坐标存储格式 | **Q12.4（int16，1/16 px）**，覆盖 ±2048 px |
| LUT 插值 | 双线性，按 §1.3 的像素中心约定 |
| 三角函数精度 | 直接调用 libm；**不得**用查表近似角度（LUT 已承担精度，另做近似会引入不可控误差） |
