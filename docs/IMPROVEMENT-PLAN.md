## 2. 原则

1. 先可测，再正确，再快，再产品化。
2. 每个修复要有负对照；关掉修复应复现旧行为。
3. 不复制参考产品参数：0_SKILL 的 b_min=200/b_max=460/b_target=300 是 3.6–8.3 km/h
   包络；NFOCC 当前 278/833/500 覆盖 5–15 km/h。
4. 不动已验收的链路：默认门控、体素融合、DVF 的测试必须继续绿。
5. 坐标约定固定：相机 OpenCV，ego ISO 8855 X 前/Y 左/Z 上；Y 右是左手系，不采用。

## 3. 剩余阶段

### P2 精度根因（下一轮）

用 6 视口 + `NF_DUMP_TRUTH` 的逐点 CSV，按视口、距离段、置信度拆分：
- 前视 1–2 m 307 mm 主要来自匹配还是三角化；
- 地面以下 11.5% 与这些点是否同源；
- 前后 ±45° 的边缘采样是否是主因。

先拆清再改算法。不要先调 SGBM 参数或加滤波。

### P3 工程化

- 0_SKILL M4 引导滤波：只在 P2 证明噪声是主因后启用；
- M6 CRC/滚动计数/共享内存：6 视口输出已稳定后再做；
- M5 Scratch Tile：上板前做；
- 在线外参校准（M2）：需要真实标定/里程计支持，优先级低于精度。

### P4 真机

RK3588 / Axera M57、INT8、5 Hz。没有 P2 的精度基线不先上板。

## 5. 已落地

- 6 视口：FV ±45°、RV ±135°（中心间隔 90°，110° 张角）；ML/MR ±90°（150°）。
- pipeline 按视口存 LUT/缓冲/视差图；SGBM 引擎一个、串行复用。
- 前后斜视按极点走径向匹配；左右 `|t_z|≈0` 走 SGBM。
- `t_veh` 车体系位移；修正 `Rz` 投影和 `pose->R` 二次旋转。
- `nf_match_radial_fast` 默认 104.6 ms（6 视口）/ 191.8 ms（4 视口）。
- `--body-mask-dir` 文件掩码；双基线方向兜底。
