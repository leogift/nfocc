## 2. 验收项（全部可跑）

### 2.1 引擎契约

| 编号 | 判据 | 实测 |
|---|---|---|
| V-ENG-1 | 容量不足返回 `NF_E_ENGINE_RANGE` 且**不写输出** | PASS |
| V-ENG-2 | 同输入两次逐位一致 | PASS |

| V-ENG-7 | 覆盖率 = `(W−numDisp)/W` | 90.0% = 90.0% |

**V-ENG-1 是本项目最重要的契约**：实测过真视差 180 px 配 `numDisparities=128`
时中位误差 89 px 但**函数成功返回**。不自查会一路错到体素。

### 2.2 三角化

| 编号 | 判据 | 实测 |
|---|---|---|
| V-TRI-1 | 真值视差三角化闭合 | **1.4e-12** |
| V-TRI-3 | `sigma_Z` 与解析式同量级 | 比值 1.49 |
| V-TRI-4 | σ 随深度单调 | 0.9 → 242 mm |

**必须用射线最小二乘，不能用 `Z=f·b/d`**（后者要求平移垂直视线，本项目不满足，

## 4. 三个 SKIP 的准确含义

| 项 | 实测 | 为什么不修 |
|---|---|---|
| V-ENG-3 精度 ≤1px | 16.0 px | 单一 SGBM 路径下的前向精度；产品路径已改用解析测距 |
| V-ENG-3 有效比例 ≥60% | 15–28% | 同上 |
| V-ENG-5 端到端 3D 精度 | 依赖上两项 | 同上 |

**这三个指标描述的是"只用 SGBM 做前向"的能力上限**，而 PH-1 的结论正是
"这条路走不通"。保留 SKIP 而不是删除，是为了让后来者知道这条路的代价。

## 5. 未完成（诚实清单）

| 项 | 影响 | 阻塞 |
|---|---|---|
| **对应点提取** | 前向测距目前用几何真值作对应点，验证的是链路本身 | 需光流/特征匹配实现 |
| 侧向残余误差 9–77 px | 深度误差 ~600 mm | 极线不平行，分块实测不划算 |
| 真实数据验证 | 合成场景不代表真实纹理/光照 | 需标定与录包 |
| 分块立体 | 已实现但默认关闭 | 收益 < 代价，见 `SPEC-FORWARD` §5.3 |

**最关键的一条是对应点提取。** 前向测距的精度链是
"对应点精度 × 灵敏度"，实测 `1px → 110 mm`、`0.5px → 55 mm`。
要做到 200 mm 体素以内，对应点必须 ≤0.5 px（亚像素）。这是下一阶段的硬指标。
