# SPEC-FOE — FoE 发散锥过滤

> **状态：已实现并接入** —— `nf_pt_in_foe` 在 `pipeline.cpp` 两处调用。

补齐审计缺口 **G-5**。本文档定义：FoE 怎么算、锥的张角由什么决定、
为什么在本系统里必须**逐相机**而不是全局、以及它与 `ROTATION_ONLY` 的边界。

---

## 1. 奇异性从哪来

深度公式 $Z = f b / d$。当视线与平移方向夹角 $\alpha \to 0$ 时：

$$d = \frac{f b \sin\alpha}{Z} \to 0 \quad\Rightarrow\quad Z \to \infty$$

**不是"深度误差大"，而是"深度不存在"**：此时该点上没有任何视差信息，
引擎给出的任何 `d` 都是噪声（或搜索区间的边界值）。

FoE（Focus of Expansion）就是 $\alpha = 0$ 的方向在图像上的投影位置。

---

## 2. FoE 的位置（精确表达，不用图像坐标）

不用"图像上的点"来定义 FoE，用**方向向量**：

$$\hat{\mathbf{e}} = \frac{R_{cv}\,t_{\text{rel}}}{\lVert t_{\text{rel}} \rVert} \tag{2.1}$$

即平移方向在相机系下的单位向量。这样定义的好处：**与视口重排无关**
（`SPEC-EPIPOLAR` §3 会改变视口朝向，图像坐标下的 FoE 位置随之变化，但方向向量不变）。

对某条视线方向 $\hat{\mathbf{r}}$（也是相机系下的单位向量），夹角：

$$\alpha = \arccos(\hat{\mathbf{e}}\cdot\hat{\mathbf{r}}) \tag{2.2}$$

---

## 3. 锥张角：可以算，不必"待标定"

### 3.1 推导

给定最小可用视差 $d_{\min}$，在距离 $Z$ 处，视差低于 $d_{\min}$ 的角度范围：

$$\sin\alpha < \frac{d_{\min}\, Z}{f\,b}
\quad\Rightarrow\quad
\alpha_{\min}(Z) = \arcsin\!\left(\frac{d_{\min}Z}{f b}\right) \tag{3.1}$$

（`arcsin` 自变量 > 1 时取 π/2，即该距离全方向不可用。）

### 3.2 关键结论：锥张角**随距离变化**

实算（`f_view=579`、`b=120 mm`、`d_min=1 px`）：

| Z | α_min |
|---|---|
| 1 m | 0.7° |
| 2 m | 1.4° |
| 5 m | 3.6° |
| 10 m | 7.2° |

**所以"用一个固定角度的锥过滤所有体素"是错的**：
固定 3° 会在近处砍掉太多（近处本该可测），固定 1° 会在远处留下太多不可信点。

### 3.3 正确的判据：不用角度，用"该点的预期视差"

对候选体素点 $P$（相机系坐标 $\mathbf{p}$），它到**平移轴**的距离是
$\lVert \mathbf{p}\times\hat{\mathbf{e}}\rVert$，而视差正比于该垂直距离：

$$d_{\text{exp}} = \frac{f\, b}{Z}\cdot\sin\alpha
= \frac{f\, b}{Z}\cdot\frac{\lVert \mathbf{p}\times\hat{\mathbf{e}}\rVert}{Z}
= \frac{f\, b\,\lVert \mathbf{p}\times\hat{\mathbf{e}}\rVert}{Z^{2}} \tag{3.3}$$

**注意 `b` 不能漏**。$\mathbf{p}\times\hat{\mathbf{e}}$ 的量纲是长度（mm），
除以 $Z^2$（mm²）得无量纲，再乘 $f b$ 得 px。

实现上**必须用叉积形式，不要用** $\sqrt{Z^2-(\hat{\mathbf{e}}\cdot\mathbf{p})^2}$：
两者数学等价，但后者在点接近 FoE（$\alpha\to 0$，正是本判据最关心的区域）时
出现**灾难性相消**，精度骤降。实测（5000 个随机点）：
叉积形式最大绝对差 `1.5e-11`，平方差形式 `2.4e-10`，后者差 16 倍。

**判据**：

$$d_{\text{exp}} < d_{\min} \implies \text{在 FoE 退化区，剔除} \tag{3.4}$$

这个形式与距离自洽、无需调张角，且与 `SPEC-EPIPOLAR` 的视差定义直接对应。

**原文档的 `MOS_ptInFoe()` 用固定 `cosApertureSq` 等价于固定张角，需要改成 (3.4)。**

---

## 4. 必须逐相机判定（4 路环视的特定问题）

### 4.1 为什么不能全局

4 路相机光轴朝向不同，`t` 是全局的。某一帧里平移方向只与其中一两路垂直。
若在**体素空间**做一次全局 FoE 过滤（原文档的做法），会同时砍掉所有相机在该方向的贡献——
而实际上只有"光轴接近平移方向"的那一路真的退化。

### 4.2 正确做法

FoE 判定放在**三角化之前、按相机**：

```
for cam in [FV, RV, ML, MR]:
    算该相机的 R_cv, t_rel          ← SPEC-POSE
    e_hat = normalize(R_cv · t_rel)  ← 该相机系下的平移方向
    对该相机视口内的每个候选点:
        若 d_exp < d_min → 该点从**这个相机**剔除
    （其它相机的贡献不受影响）
```

**同一物理点可能被 FV 剔除、却被 ML 保留**——这是正确的，
因为 ML 看到它的角度不同，视差足够。

### 4.3 与 `SPEC-EPIPOLAR` 视口重排的关系

视口重排使视差沿视口水平方向呈现，但**不改变**该点是否存在奇异性
（奇异性只取决于 $\mathbf{p}$ 与 $t$ 的夹角）。所以 FoE 过滤在重排前后都必需，
不能因为"已经极线对齐"就省掉。

---

## 5. 与 `ROTATION_ONLY` 的边界（两者互补，不重叠）

| | FoE 过滤 | `ROTATION_ONLY` 冻结 |
|---|---|---|
| 触发条件 | 平移存在，但**某些方向**的视线与之平行 | **平移本身消失**（原地打方向） |
| 作用范围 | 部分体素 | 整帧 |
| 判定层 | 三角化前，逐相机 | 基线状态机，全局 |
| 后果 | 该方向缺体素 | 无输出 |

**边界规则**：
- `‖t_rel‖ ≥ B_MIN` 且状态为 `VALID` → 做 FoE 过滤；
- 状态非 `VALID` → 根本不进引擎，无需 FoE；
- **不允许**用 FoE 锥去"补救"纯旋转（`SPEC-BASELINE-SM` T-3 已经冻结了整个帧）。

## 6. 参数

| 参数 | 值 | 说明 |
|---|---|---|
| `FOE_D_MIN` | 1.0 px | FoE 判据中的最小可用视差 |
| `FOE_APEX_SIGMA` | 2.0 | 平移方向的 2σ 包络（见 §6.1） |

### 6.1 apex 的不确定性

`t_rel` 由位姿给出，有误差 `σ_t`。判据 (3.3) 里的 `ê` 因此有方向误差：

$$\sigma_\alpha \approx \frac{\sigma_t}{b} \tag{6.1}$$

`b=120 mm`、`σ_t=2 mm` 时 `σ_α ≈ 0.95°`，在 5 m 处对应 `d_exp` 变化约 0.25 px。

**处理方式**：判据 (3.4) 里把 `d_min` 抬高到 `d_min + 2σ_α·f·b/Z` 即可，
**不需要**构造"锥的包络"这种几何对象。原文档的"点 vs 锥的包络"在实现上更复杂且等价。

## 7. 验收

| 编号 | 级别 | 判据 | 负例（必须失败） |
|---|---|---|---|
| V-FOE-1 | L0 | (3.3) 与 (3.1) 在数值上一致（同一 α） | 用固定角度替代 (3.3) → 近/远同时出错 |
| V-FOE-2 | L0 | 正对平移方向的点 `d_exp → 0`，被剔除 | — |
| V-FOE-3 | L0 | 与平移垂直的视线 `d_exp = f·b/Z`，不被剔除 | — |
| V-FOE-4 | **L0** | **直行时 FV 的 FoE 区被剔除、ML 的同方向点保留** | **全局过滤 → ML 被一起砍掉** |
| V-FOE-5 | L0 | `ROTATION_ONLY` 帧不做 FoE 计算（引擎调用为 0） | 靠 FoE 补救 → 引擎仍被调用 |
| V-FOE-6 | L0 | `d_min` 含 `2σ_α` 补偿后，边界不随 `t_rel` 抖动 | 不加补偿 → 边界闪烁 |

**V-FOE-4 是本规范的核心**：构造直行场景，取一个位于 FV 视场 FoE 附近的点，
验证 FV 剔除它、而 ML 若能看到它则保留。全局实现会两者都剔除。
